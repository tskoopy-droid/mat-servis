// M&T Servis — vin_ocr.gs (rozpoznání VIN z fotky přes Google Cloud Vision) // // Stránky (oleje.html, vin.html) posílají fotku sem, ne přímo do Vision — // klíč tak není ve veřejném kódu webu. // Zprovoznění: Vlastnosti skriptu → VISION_API_KEY = klíč z Google Cloud // (klíč může být omezený na web mat-servis.cz — GAS posílá Referer webu). // doPost: if (data.akce === 'vin_ocr') return vin_ocr_(data); // Pojistky proti zneužití veřejné adresy. Vision je zdarma do 1 000 rozpoznání // měsíčně — měsíční strop 900 drží provoz vždy v bezplatném limitu, i kdyby // někdo adresu zahlcoval. Pak skenování do konce měsíce nejde, VIN se zadá ručně. const VIN_OCR_MAX_ZA_MESIC = 900; const VIN_OCR_MAX_ZA_HODINU = 30; const VIN_OCR_MAX_DELKA = 4000000; // base64 ≈ 3 MB fotky; stránky zmenšují na 1600 px // Vrací odpověď Vision beze změny, aby stránky mohly číst výsledek stejně jako dřív. function vin_ocr_(data) { const klic = PropertiesService.getScriptProperties().getProperty('VISION_API_KEY'); if (!klic) { errors_log_('vin_ocr_', '', 'VISION_API_KEY není nastaven', 0, 'konfigurace', 'vision'); return jsonResp({ error: { message: 'Rozpoznávání není nastavené' } }); } const obrazek = String((data && data.obrazek) || ''); if (!obrazek) return jsonResp({ error: { message: 'Chybí fotka' } }); if (obrazek.length > VIN_OCR_MAX_DELKA) return jsonResp({ error: { message: 'Fotka je příliš velká' } }); if (!vin_ocr_povolit_()) { return jsonResp({ error: { message: 'Skenování je teď nedostupné' } }); } const r = UrlFetchApp.fetch('https://vision.googleapis.com/v1/images:annotate?key=' + encodeURIComponent(klic), { method: 'post', contentType: 'application/json', // Klíč může být omezený na web mat-servis.cz (HTTP referrer) — GAS se proto ohlásí jako web. headers: { Referer: 'https://mat-servis.cz/' }, muteHttpExceptions: true, payload: JSON.stringify({ requests: [{ image: { content: obrazek }, features: [{ type: 'TEXT_DETECTION', maxResults: 1 }] }] }) }); if (r.getResponseCode() !== 200) { errors_log_('vin_ocr_', '', 'Vision HTTP ' + r.getResponseCode(), r.getResponseCode(), r.getContentText().slice(0, 500), 'vision'); } return ContentService.createTextOutput(r.getContentText()).setMimeType(ContentService.MimeType.JSON); } // Započítá rozpoznání do hodinového a měsíčního počítadla; false = limit vyčerpán. // Měsíční počet je ve Vlastnostech skriptu (cache by ho mohla ztratit), // zámek brání tomu, aby souběžné požadavky limit přeskočily. function vin_ocr_povolit_() { const zamek = LockService.getScriptLock(); if (!zamek.tryLock(10000)) return false; try { const ted = new Date(); const props = PropertiesService.getScriptProperties(); const klicMesice = 'VIN_OCR_POCET_' + Utilities.formatDate(ted, 'Europe/Prague', 'yyyyMM'); const zaMesic = Number(props.getProperty(klicMesice) || 0); if (zaMesic >= VIN_OCR_MAX_ZA_MESIC) { if (zaMesic === VIN_OCR_MAX_ZA_MESIC) { // zapsat jen jednou, ne při každém dalším pokusu errors_log_('vin_ocr_', '', 'Vyčerpán měsíční limit rozpoznání', 0, String(zaMesic), 'vision'); props.setProperty(klicMesice, String(zaMesic + 1)); } return false; } const cache = CacheService.getScriptCache(); const klicHodiny = 'vin_ocr_' + Utilities.formatDate(ted, 'Europe/Prague', 'yyyyMMddHH'); const zaHodinu = Number(cache.get(klicHodiny) || 0); if (zaHodinu >= VIN_OCR_MAX_ZA_HODINU) { if (zaHodinu === VIN_OCR_MAX_ZA_HODINU) { errors_log_('vin_ocr_', '', 'Překročen hodinový limit rozpoznání', 0, String(zaHodinu), 'vision'); cache.put(klicHodiny, String(zaHodinu + 1), 3700); } return false; } cache.put(klicHodiny, String(zaHodinu + 1), 3700); props.setProperty(klicMesice, String(zaMesic + 1)); return true; } finally { zamek.releaseLock(); } }
